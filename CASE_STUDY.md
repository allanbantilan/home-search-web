# Home Search: real estate search experience

**Problem.** Buyers need a quick way to narrow a large listing collection and decide which homes deserve a visit. Agents need each viewing request to reach the right person.

**Solution.** Home Search combines editorial property pages with live filtering, a map, saved homes, three home comparison, and a payment estimate. Viewing requests route to the assigned agent.

**Build.** WordPress custom post types, ACF field groups, `WP_Query`, a WordPress REST route, Leaflet, and a small JavaScript layer. The interface follows UI UX Pro Max guidance for contrast, keyboard access, labeled controls, touch targets, responsive layout, and reduced motion.

**Result.** The local WordPress installation passed route, search, form, and browser checks. Its current mobile Lighthouse scores are 88 performance and 100 for accessibility, best practices, and SEO. Live delivery and conversion outcomes require a production deployment with real listings and an active sales team.
